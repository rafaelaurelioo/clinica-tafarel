# Clinica Tafarel
Landing page desenvolvida para uma clinica  de saúde fictícia.

## Sobre
o projeto tem como função criar uma página para uma clinica, com equipe fictícia, e um formulário de contato, que não manda os dados para nenhum lugar, sendo estático.

## Tecnologias usadas
- Html
- CSS
- GitHub(repositorio)

## Funcionalidades
- Página inicial da clínica
- Apresentação dos serviços
- Apresentação da equipe
- Formulário de contato estático
- Navegação entre as seções da página
- Design responsivo

## Como executar

### Online

O projeto está disponível em:

https://rafaelaurelioo.github.io/clinica-tafarel/

### Localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Execute utilizando o Live Server.
